# mk-events-organizing

Static multi-page preview site for MK Events Organizing Services, built by Stallion.

- Stack: HTML + CSS + JS, no backend, Vercel-ready (deploy the folder as a static site).
- Pages: Home, Portfolio (motif and event filters, lightbox), Packages, Reviews, Check your date (Smart Inquiry Form sent via Messenger or SMS), Wedding website demo (countdown + RSVP).
- Signature: motif switcher on Home re-themes the whole site (Emerald, Blue Gold, Purple); arch-shaped frames throughout.
- Fonts self-hosted in assets/fonts (Bodoni Moda, Figtree, Pinyon Script; SIL Open Font License, via Fontsource).
- Placeholders: see content/content.md.
